# BMC Generator — Digital CX Ancol

Static browser-based Business Model Canvas editor for Digital CX Ancol.

## Features

- Edit canvas content directly in the browser
- Adjust and auto-fit text size
- Export PNG, JPG, SVG, or PDF
- Save and load canvas content as JSON

All editing and exports run locally in the browser. No data is sent to a backend.
